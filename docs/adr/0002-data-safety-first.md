# 数据安全优先于便利：三道防线

转换是破坏性原位覆写，磁盘写盘没有撤销。定下三条防线，每条都在便利性上付出代价，均为刻意选择：

1. **脏缓冲拒绝（不可配置）**：文件在编辑器中有未保存修改时拒绝转换。否则用户随后 Ctrl+S 会用旧缓冲内容覆盖转换结果——静默数据丢失。
2. **不可映射字符默认硬失败（可配置为替换 '?'，默认否）**：目标编码装不下的字符导致该文件不写盘并报告字符位置。批量时跳过该文件、继续其余、最后汇总。
3. **二进制防护（不可配置）**：首 8KB 含 NUL 字节或命中二进制扩展名表的文件强制跳过，报告为"疑似二进制"。

## Considered Options

被否决：提供"跳过所有保护"总开关——批量场景下误用必然发生，防线的价值正在于不可绕过；事前控制由文件夹批量的强制预览承担。
